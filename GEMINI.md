# Spécificités Gemini

> La référence est `AGENTS.md`, importé ci-dessus avec la syntaxe `@fichier` de Gemini CLI (Antigravity CLI, lui, le lit directement). **En cas de conflit, `AGENTS.md` prime.** Ce fichier n'ajoute que ce qui est propre à Gemini.

- **Gemini CLI ou Antigravity CLI** : depuis le 18/06/2026, Gemini CLI n'est plus servi aux comptes personnels (gratuit, Google One, Google AI Pro et Ultra) : il est remplacé par Antigravity CLI (sources : bandeau de https://geminicli.com/docs/ ; https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli ; https://antigravity.google/docs/rules).
  - **Antigravity CLI** lit directement `AGENTS.md` et `GEMINI.md` à la racine (limite 24 000 octets par fichier) ; la syntaxe `@fichier` n'y insère pas le contenu ; `/memory show` et `context.fileName` ne s'y appliquent pas.
  - **Gemini CLI** reste utilisable avec une clé API payante ou Code Assist Standard/Enterprise : dans ce cas, l'import `@./AGENTS.md`, `/memory show` et `context.fileName` restent valables ; `.gemini/settings.json` est ignoré dans un dossier non approuvé.
- **Vérifier le chargement** (contrôle commun) : demande à l'IA « Cite mot pour mot la règle RG-08 d'AGENTS.md ». Avec Gemini CLI, lance aussi `/memory show` : le contenu d'`AGENTS.md` doit apparaître. S'il est absent, parce que ta version de Gemini CLI ne gère pas l'import :
  - **solution A** (Gemini CLI, dossier approuvé) : déclarer `AGENTS.md` comme fichier de contexte dans `.gemini/settings.json`. La clé dépend de ta version : `"context": { "fileName": ["AGENTS.md", "GEMINI.md"] }` sur les versions récentes, `"contextFileName": ["AGENTS.md", "GEMINI.md"]` sur les anciennes. Consulte `/help` ou la documentation de ta version ;
  - **solution B** : commencer la session par « Lis AGENTS.md en entier et applique-le. »
- **Démarrage** : applique le protocole de `AGENTS.md` §0. Présente l'audit et le plan, puis attends la validation avant toute écriture (fichiers, `git add`, `commit`, `tag`, `push`). Les commandes en lecture seule de l'audit (`git log`, `git status`, `git diff`, `git show`, `git tag -l`, `Get-FileHash`) sont autorisées avant la validation humaine. `git pull` et `git fetch --tags` du démarrage sont lancés par l'humain (`ETAT_PROJET.md` §6, étape 1) avant d'ouvrir l'IA.
- **Gemini web** (gemini.google.com) : il ne voit pas le dépôt. Utilise le kit de `AGENTS.md` §13, qui fait foi (liste et ordre : `AGENTS.md`, `ETAT_PROJET.md`, `agents/00_protocole_relais.md`, ta fiche et celle du relais suivant, `travail/decisions.md` et les deux journaux, les fichiers d'entrée ; coller la sortie de `git log --oneline -15`, `git status` et `git tag -l` ; pour R2, joindre aussi le .docx et le PDF originaux), demande des modifications ciblées, puis reporte-les toi-même dans les fichiers et relis `git diff --cached` après le bloc A (protocole, variante web). Pour le journal de bord et la passation, suis la « Variante pour une IA web » du protocole (§4).
- **Délégation du Sprint 01** : ne produis **jamais** `version_IA.html` depuis une session qui a lu ce dépôt. Le relais R4 utilise une session vierge (D-09) : de préférence une IA web dans une conversation temporaire (ou nouvelle), mémoire et instructions personnalisées du compte désactivées, hors de tout Projet, Gem ou GPT personnalisé, sans autre pièce jointe que le prompt. En ligne de commande, uniquement `claude --safe-mode` lancé dans un dossier temporaire vide hors du dépôt (il désactive `CLAUDE.md`, règles, skills, plugins et hooks). Codex, Gemini CLI ou Antigravity CLI seulement si aucun fichier d'instructions global n'existe (`~/.codex/AGENTS.md`, `~/.gemini/GEMINI.md`). Raison : une CLI ouverte dans un dossier vide charge quand même les instructions globales de l'utilisateur (`~/.claude/CLAUDE.md`, `~/.claude/rules/`, `~/.codex/AGENTS.md`). Noter le mode exact dans `prompts.md` §1. Si la CLI écrit elle-même le fichier, le copier tel quel vers `version_IA.html` et garder la transcription dans `travail/brut/`. Si l'IA pose une question au lieu de livrer, répondre uniquement « Applique les hypothèses du cahier des charges et livre le fichier complet. » et consigner l'échange dans `prompts.md` §1. Avant le commit de `version_IA.html`, contrôler qu'il est identique au bloc HTML de la réponse brute : `git diff --no-index --ignore-cr-at-eol <bloc extrait dans un fichier temporaire hors dépôt> <version_IA.html>` doit être vide.
