# Spécificités Claude Code

> La référence est `AGENTS.md`, importé ci-dessus. **En cas de conflit, `AGENTS.md` prime.** Ce fichier n'ajoute que ce qui est propre à Claude Code.

- **Démarrage** : applique le protocole de `AGENTS.md` §0. Pour présenter l'audit et le plan avant toute modification, utilise de préférence le **mode plan** (lancer `claude --permission-mode plan`, ou Maj+Tab jusqu'à l'indicateur « plan » ; dans l'application de bureau, choisir « plan » dans le sélecteur de mode). À l'acceptation du plan, choisis l'acceptation automatique des modifications : le journal de bord se met alors à jour sans invite à chaque ligne. Pour une reprise (« reprise du relais »), lance Claude Code sans le mode plan.
- **Priorité sur les instructions globales** : si ton `~/.claude/CLAUDE.md` ou tes règles personnelles imposent des conventions génériques, elles **ne s'appliquent pas** à ce dépôt lorsqu'elles contredisent `AGENTS.md`. C'est le cas, par exemple, du TDD obligatoire, d'une couverture de 80 %, de « nombreux petits fichiers », de frameworks ou de sous-agents de revue systématiques. Ici, le prototype est un fichier HTML unique sans outillage. Si ton `~/.claude/CLAUDE.md` décrit un autre projet, ignore-le ici : ne crée aucun fichier que `AGENTS.md` §10 ne prévoit pas.
- **Fiches de rôle** : elles sont dans `agents/*.md`, en markdown simple, communes à toutes les IA. Pas besoin de sous-agents `.claude/agents/`.
- **Délégation du Sprint 01** : ne produis **jamais** `version_IA.html` depuis une session ouverte dans ce dépôt, car elle a lu `AGENTS.md`. Le relais R4 lance l'IA déléguée dans une session vierge (D-09) : de préférence une IA web dans une conversation temporaire (ou nouvelle), mémoire et instructions personnalisées du compte désactivées, hors de tout Projet, Gem ou GPT personnalisé, sans autre pièce jointe que le prompt. En ligne de commande, uniquement `claude --safe-mode` lancé dans un dossier temporaire vide hors du dépôt (il désactive `CLAUDE.md`, règles, skills, plugins et hooks). Codex, Gemini CLI ou Antigravity CLI seulement si aucun fichier d'instructions global n'existe (`~/.codex/AGENTS.md`, `~/.gemini/GEMINI.md`). Raison : une CLI ouverte dans un dossier vide charge quand même les instructions globales de l'utilisateur (`~/.claude/CLAUDE.md`, `~/.claude/rules/`, `~/.codex/AGENTS.md`). Noter le mode exact dans `prompts.md` §1. Si la CLI écrit elle-même le fichier, le copier tel quel vers `version_IA.html` et garder la transcription dans `travail/brut/`. Si l'IA pose une question au lieu de livrer, répondre uniquement « Applique les hypothèses du cahier des charges et livre le fichier complet. » et consigner l'échange dans `prompts.md` §1. Avant le commit de `version_IA.html`, contrôler qu'il est identique au bloc HTML de la réponse brute : `git diff --no-index --ignore-cr-at-eol <bloc extrait dans un fichier temporaire hors dépôt> <version_IA.html>` doit être vide.
- **Git** : ne commite et ne pousse qu'à la demande de l'humain du relais. Les phrases « fin de notre relais » et « sauvegarde du relais » valent cette demande (`AGENTS.md` §9, `agents/00_protocole_relais.md`) ; avant de les exécuter, relis le protocole (§3.6, §4 et §5), car le contexte a pu être compacté. Lance les deux blocs Git de l'étape 7 en appels séparés. Commite directement sur `main`, sans créer de branche, même si ton outil le recommande (AGENTS.md §11). Si `git commit` ou `git push` déclenche une demande d'approbation, préviens le membre : c'est à lui de l'accepter. Messages au format conventionnel, en français (AGENTS.md §11).
- **Journal de bord** : tiens `ETAT_PROJET.md` §8 à jour pendant le relais (une ligne par étape terminée), sans redemander l'accord à chaque ligne : la validation du plan le couvre.
- **Mémoire** : ne stocke rien dans la mémoire automatique de Claude qui ne soit pas aussi écrit dans le dépôt. Le relais suivant utilise peut-être une autre IA.
